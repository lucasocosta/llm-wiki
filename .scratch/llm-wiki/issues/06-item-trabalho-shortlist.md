# 06: Item de trabalho com shortlist ranqueada e as tools do trabalhador

**What to build:** O trabalhador passa a saber o que já existe na wiki sem que o índice inteiro entre no contexto dele. O item de trabalho carrega o Trecho mais uma shortlist ranqueada dos conceitos vizinhos daquele Trecho, e o trabalhador dispõe de exatamente três capacidades: buscar, ler página e gravar página. É o que faz um segundo Trecho sobre o mesmo assunto augmentar a página existente em vez de criar uma duplicada.

**Blocked by:** 03, 05.

**Status:** done

- [x] O item de trabalho traz o Trecho extraído e uma shortlist ranqueada de conceitos vizinhos
- [x] A shortlist tem tamanho limitado; o índice inteiro nunca é entregue
- [x] O trabalhador dispõe de buscar, ler página e gravar página, e de mais nada
- [x] O trabalhador não alcança nenhum comando de curador
- [x] Um segundo Trecho sobre o mesmo conceito encontra o id existente pela shortlist
- [x] O conteúdo da shortlist é verificável sobre fixtures conhecidas
